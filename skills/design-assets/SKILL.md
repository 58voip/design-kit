# 设计素材库

正式库位于 `~/design`。按[素材索引](../../docs/shared/visual-assets.md)选品牌标记、线条图标或插画。总览是查找入口，实际交付取对应源文件。

## 找到原件

- 用 `python3 ~/design/scripts/find-design-asset.py "名称"` 查绝对路径。可加 `--kind icon`、`--kind brand` 或 `--kind illustration`。也可以从[绘制清单](../../docs/shared/icon-briefs.md)按中文名称或英文文件名找线条图标。
- 先区分同名素材的用途。比如「PMS 系统」是通用酒店系统，「3CX PMS 模块」带 3CX Logo。「SIP 终端」通常指通用桌面话机，明确接入 3CX 时选带 3CX Logo 的版本。
- 单独索取图标时，返回原件链接和名称即可。多项候选会改变表达含义时，说明差别。库里缺项时，标明缺的是什么及最接近的现有素材；确需新绘时读[图标规范](../../docs/shared/icon-system.md)。

## 放进作品

- **拓扑图规范**：制作或修改拓扑图时，读取 `~/design/docs/images/topology-style.md`，使用 `topology-diagram` 技能统一线路、连接点、白底、Logo 和精简文案。这里只索取图标时不必读取整套拓扑规范。
- **PPT 或拓扑图**：沿用当前交付工具和模板。优先使用能正确嵌入和渲染的 SVG，目标不支持 SVG 时用透明 PNG。完成后检查导出的文件内图标仍可见、比例正确，离开本机素材路径也能显示。
- **图片**：在支持矢量的排版工具中直接使用 SVG。做位图合成时，按成图尺寸渲染透明 PNG，保留四周空隙和品牌原色。需用千问灰色版时，优先用库中已有的灰色 PNG。
- **视频**：沿用 `video` 技能及[视频制作规范](../../docs/workflow.md)。需要逐段动效时，从 SVG 的 `body`、`accent`、`brand` 分层取用；位图渲染时检查透明边缘和实际播放尺寸。

需要转换或制作可移交的项目时，把派生文件放在当前项目的素材目录。用户要求更新素材库时，同义图标沿用原文件名，并同步清单和预览。

## 新图标自动入库（2026-11-11）

每次制作中新生成的图标，默认保存到正式素材库并更新使用说明，无需再次询问。先查库避免重复；已有图标直接复用，同义重绘沿用文件名。新绘图标遵循正式 Wired Outline 规范，以独立透明 SVG 保存到 `~/design/assets/icons/`；品牌原件归入 `assets/brands/` 并记录来源。同步 `docs/shared/icon-briefs.md` 的英文文件名、中文名称、绘制说明三列，补充适用场景及易混淆区别；运行 `scripts/render-icon-preview.py` 更新预览，检查 36 px、48 px 与放大效果，作品引用入库原件。整页生成图里的图形不能算已入库原件；需要复用时单独重建和校验，不以带背景或文字的裁切图替代透明源文件。项目派生素材留在项目目录，正式原件只维护一份。

小红书案例补充：`employee-phone` 表达员工电话协作，`review-checklist` 表达审查要求，`database-readonly-review` 表达数据库查询审查，不表示实际数据库管理界面；通用摘要仍使用 `summary`。

SBC 选用：通用或未明确为 3CX 品牌时用 `sip-sbc.svg`；仅明确为 3CX SBC 时用 `3cx-sbc.svg`。

## 图标选择与新绘顺序

先查正式库，已有合适含义就复用；缺少时才按 `docs/shared/icon-system.md` 新绘。轮廓、内部符号和边框之间必须保留可见空白，按描边外缘检查，避免相邻线条粘连。间隙不足时拉开距离、删减细节或调整比例；复核放大图、36 px、48 px 与作品实际尺寸。检查后保存独立 SVG 入库并更新清单、预览及使用说明，作品嵌入该原件。
