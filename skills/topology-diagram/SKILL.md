# 拓扑图

先读取正式规范 `~/design/docs/images/topology-style.md`，按其中的线路、连接锚点、白底、品牌和文字规则制作。用户当次指定的要求优先；不要把某张示例图的设备与连接关系固定为所有拓扑的模板。

素材来自 `~/design`。通过 `python3 ~/design/scripts/find-design-asset.py "名称"` 查原件；需要区分同名素材时读 `~/design/docs/shared/visual-assets.md`。3CX 图保留正式 Logo，明确接入 3CX 的话机优先选带 3CX 标记的图标。

先确定需要表达的节点和连接层次，再按规范为各连接选择线型。物理接线与逻辑 SIP 关系分别表达，避免为满足视觉布局制造错误的连接。未提供的型号、IP 和数量用通用节点或必要说明处理；仅设计图不自动查询或修改生产系统。

沿用可编辑的矢量排版方式；修改现有 SVG 或代码生成的拓扑时优先编辑源文件。默认在 `~/design/projects/images/` 的对应项目目录保存 SVG、PNG 和必要源文件，嵌入图标及 Logo，按正式规范完成渲染检查。架构依据、来源和部署说明放项目说明，图内按用户标注保留必要细节；精简不等于删除全部次级标签。主标题前使用蓝色向右箭头，保留分区编号。

正式规范为唯一维护来源；更新样式时修改该规范，避免在技能和各项目中复制多份互相冲突的规则。
