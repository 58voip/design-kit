# 视频制作

从 `仓库根目录` 的[正式素材库](../../docs/visual-assets.md)选品牌图标、线条图标和插画。需要按中文名称找原件，或要把同一素材复用到 PPT、图片和视频时，沿用 [design-assets 技能](../design-assets/SKILL.md)的查找与取用流程。

每次使用本技能时，先读取[视频制作规范](../../docs/workflow.md)的当前版本。它保存本人的视频视觉、制作与交付约定。本次明确要求优先于默认值。

制作 3CX 视频时在按规范在右下角放置项目已确认可用的灰色 3CX Logo，配白色为主的灰白渐变、Wired Outline 风格的中灰细线图标与少量 3CX 蓝。单个动效画面只保留一个主标题和一个副标题。用图标的轻跳、移动和连线表达流程。绘制或选用 3CX 图标时，读取[图标规范](../../docs/icon-system.md)，优先复用其中已确认的 SVG，新绘和重绘按 Wired Outline 规范并排校对。业务界面截图按其实际界面呈现，视频本身的品牌角标仍放在右下角。

先根据用户提供的资料确定受众、事实边界和交付物，再完成分镜、配音、字幕、渲染及验收。请求制作视频时交付可播放的成片。实际输出、源文件和检查记录放在任务指定的项目目录，未指定时创建独立的项目输出目录。根据实际检查结果说明未完成的验收项。
