# 视频制作规范

2026-11-09。适用于个人产品介绍、功能演示和教程视频。3CX 品牌规则用于 3CX 相关视频，其他产品按其品牌资料设置标识与强调色。当次需求可以覆盖本规范的默认值。

## 3CX 视频视觉

- **背景以白色为主。** 用白到浅灰的柔和渐变。起点可用 #FFFFFF，过渡色可用 #F2F4F6。文字与线条默认深灰，保持字幕和主要信息清晰。
- **3CX Logo 固定在右下角。** 使用项目中经确认可用的灰色 3CX Logo。透明素材直接叠在灰白背景上，保持原色、原比例和完整标记。从片头到片尾固定位置与尺寸，预留边距和字幕安全区。
- **单个动效画面只保留一个主标题和一个副标题。** 用图标和动作表达其余信息。方案编号、镜头说明、图标标签、页脚等放在画面之外。按需求交付的字幕作为独立轨道或 SRT；明确要求内嵌字幕时，避免与副标题重复。必要的示意标记可并入副标题。
- **线条图标负责讲故事。** 按[Wired Outline 图标规范](icon-system.md)绘制和复用 SVG。用圆角空心描边和留白区分主体，用中灰画轮廓，关键局部和流动路径用 3CX 蓝。
- **动效以轻跳和移动为主。** 用轻跳表示来电或触发，平移表示转移或送达，用线条延伸表示连接。每次变化跟着旁白或流程状态，同一时刻优先突出一个动作。字幕和 Logo 保持稳定。
- **画面规则与业务界面分开。** 视频的右下角 Logo 是品牌角标。画面中的真实界面保留原布局，示意界面明确标注。遇到其他产品，按其品牌资料调整。

## 素材选用

按[素材分类](visual-assets.md)分别从品牌图标库、线条图标库或插画库取用。插画的通用规范待定。

## 制作顺序

1. 确定受众、一个核心场景和要讲清的流程。核对功能与证据，示意场景用虚构内容，未验收的功能表述保留边界。
2. 按镜头编排旁白、字幕和画面动作。先检查代表性画面里的 Logo、图标、对比度与字幕安全区，再渲染全片。
3. 根据旁白实际时长对齐字幕和画面。短产品介绍未指定规格时，默认约 80 秒、16:9、1080p、中文旁白与字幕。已有明确规格时直接使用。
4. 合成可播放 MP4，保留旁白稿、SRT、渲染与剪辑源文件和重建所需素材。工具依任务选择。可用矢量或程序绘图制作线条动效，再用 FFmpeg 合成音画。

## 验收与交付

- 检查成片分辨率、时长、完整解码、音量和削波。核对字幕内容、时码和是否遮住主画面。
- 抽查片头、关键场景、转场及片尾，核对灰白背景、右下角灰色版 Logo、一个主标题与一个副标题、描边与蓝色强调、动效节奏。能播放时检查实际播放与旁白，单独记录解码检查和播放器验收结果。
- 随成片提供旁白稿、字幕和可编辑源文件。保留必要素材、配音和重建方法。无法渲染或验收时说明具体阻碍和已交付内容。
