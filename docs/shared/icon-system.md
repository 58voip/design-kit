# 设计图标规范 · Wired Outline

以用户确认的细线版为正式标准（2026-11-10），用于视频、拓扑图和其他设计画面。可复用的 SVG 存在[共用图标目录](../../assets/icons)。设备图标及分组预览见[图标绘制清单](icon-briefs.md)，通用图标见[通用图标预览](icon-preview.png)。

- **轮廓优先。** 用圆角空心描边勾勒主体，靠外轮廓和少量结构线分辨对象，例如屏幕和支架、浏览器地址栏或服务器面板。在合适的外框或面板上留一处小缺口，避开承担识别作用的转角和连接处。图标使用透明背景。
- **线宽统一。** 本地 SVG 使用 `24 × 24` 画布，主线 `0.56`，内部细节及设备内的空心听筒 `0.46`，圆头圆角。预览时同时看放大效果、48 px 和 36 px，优先用留白和少量结构线保持辨识度。
- **按最小使用尺寸取舍细节。** 在 36 px 下先看主体轮廓，再看区分同类图标的特征。去掉某条线后仍能认出对象，且留白更清楚，就省去这条线。并列部件先对齐边缘，再比较左右的大小、留白和线条密度。
- **留出清楚的线间空隙。** 看描边外缘之间实际剩下的空白。除有意连接的线条外，相邻轮廓、内部符号、Logo 和边框在 36 px 下应能分开。空隙过小时，优先拉开距离或删去次要线条。
- **按内容调整图标比例。** 端口横排较多时，可适当加宽机壳；Logo 与符号纵排时，可适当加高主体。把增加的空间留给必要元素之间的间隔和外框留白，线宽与 Logo 比例保持一致。用 36 px 和 48 px 并排复核，确保扩展后的图标与同组图标视觉大小协调。
- **双颜色分层。** 主体 `data-part="body"` 用中灰 `#68737C`。强调 `data-part="accent"` 用 3CX 蓝 `#0596D4`，只点亮能帮助读懂对象或动作的部位。品牌标记独立放入 `data-part="brand"`，保留官方字标、颜色和比例。
- **3CX Logo 在上。** 带 3CX Logo 的图标采用上下构图。设备屏幕或面板内，Logo 放在内容区上方，听筒、视频符号、端口或状态灯等识别元素放在下方。两层之间留出清楚的空隙。
- **设备内图形。** 听筒用空心细描边，与 Logo 和边框留开。Windows 软电话用单层应用窗口和窗口控制图形，网页软电话用浏览器地址栏。
- **锚点与动画。** 中心锚点为 `(12, 12)`，水平连接点为 `(0, 12)` 和 `(24, 12)`。入场可用线条依次出现，强调可用轻微回弹或关键部位变形。SVG 保存轮廓与颜色分层，分镜定义时序和移动方向。
- **按编号复用。** 分镜使用去掉 `.svg` 后的文件名。重绘同一含义的图标沿用编号，新增含义使用新编号。使用外部图标原件时在素材记录里留存来源和许可。

## 新图标自动入库（2026-11-11）

每次制作中新生成的图标，默认保存到正式素材库并更新使用说明，无需再次询问。先查库避免重复；已有图标直接复用，同义重绘沿用文件名。新绘图标遵循正式 Wired Outline 规范，以独立透明 SVG 保存到 `~/design/assets/icons/`；品牌原件归入 `assets/brands/` 并记录来源。同步 `docs/shared/icon-briefs.md` 的英文文件名、中文名称、绘制说明三列，补充适用场景及易混淆区别；运行 `scripts/render-icon-preview.py` 更新预览，检查 36 px、48 px 与放大效果，作品引用入库原件。整页生成图里的图形不能算已入库原件；需要复用时单独重建和校验，不以带背景或文字的裁切图替代透明源文件。项目派生素材留在项目目录，正式原件只维护一份。
